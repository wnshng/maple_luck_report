# 메이플 운빨 리포트

Nexon Open API 기반으로 메이플스토리 큐브, 잠재능력 재설정, 스타포스 히스토리를 가져와 개인 운 좋은 요일, 시간대, 1시간 단위 시간, 유효옵션 출현률을 분석하는 Streamlit MVP입니다. 참고 서비스인 츄츄지지처럼 개인 히스토리를 통계 리포트로 보여주는 포트폴리오/사이드 프로젝트용 웹앱입니다.

## 주요 기능

- Nexon Open API Key 직접 입력 기반 히스토리 조회
- 넥슨 게임 데이터 활용 로그인 UI 안내 및 향후 확장용 `auth.py` 구조
- 큐브, 잠재능력 재설정, 스타포스, 전체 데이터 조회
- 공식 API 제한에 맞춘 날짜 범위 자동 보정
- `next_cursor` 기반 페이지네이션 전체 수집
- raw JSON과 processed CSV 저장
- CSV 업로드 기반 오프라인 재분석
- 요일, 4구간 시간대, 0~23시 1시간 단위 분석
- 큐브/잠재능력 재설정 유효옵션 출현률 분석
- 채널 필드가 있을 때만 채널별 분석 자동 활성화
- 스타포스 응답 구조 확인용 API 디버그 탭

## 화면 예시

- 큐브 운 리포트: 총 사용 횟수, 등급업률, 유효옵션률, 최고 운 좋은 요일/시간
- 스타포스 운 리포트: 총 시도 횟수, 성공률, 파괴/하락 횟수, 최고 운 좋은 요일/시간
- 유효옵션 분석: 선택한 직업/주스탯 기준의 요일별, 시간별, 큐브 타입별 출현률
- 시간 분석: 큐브 등급업률, 큐브 유효옵션률, 스타포스 성공률의 0~23시 그래프
- API 디버그: 마지막 path, `params`, response keys, `count`, `record_key_exists`, `record_count`, `next_cursor_exists`

## 설치 방법

```bash
cd maple_luck_report
python3 -m venv .venv

```

## 실행 방법

```bash
streamlit run app.py
```

브라우저에 표시되는 로컬 URL로 접속한 뒤 사이드바에서 API Key, 데이터 종류, 날짜 범위, 유효옵션 기준을 선택합니다.

## .env 설정 방법

`.env.example`을 참고해 프로젝트 루트에 `.env` 파일을 만들 수 있습니다. 기본 방식은 사이드바 입력이며, `.env`는 로컬 개발 편의를 위한 보조 수단입니다.

```bash
NEXON_OPEN_API_KEY=발급받은_API_KEY
```

API Key는 raw JSON, CSV, 로그, 디버그 화면에 저장하거나 출력하지 않습니다.

## API Key 발급 방법 요약

1. [Nexon Open API](https://openapi.nexon.com/)에 넥슨 계정으로 로그인합니다.
2. 애플리케이션을 등록합니다.
3. 애플리케이션 상세 화면에서 API Key를 확인합니다.
4. Streamlit 사이드바에 API Key를 입력합니다.

일반 Open API 호출은 요청 헤더 `x-nxopen-api-key`에 API Key를 넣어 사용합니다.

## 넥슨 게임 데이터 활용 로그인

현재 MVP는 API Key 직접 입력 방식만 실제 동작합니다. 메애기/츄츄지지처럼 사용자가 넥슨 로그인으로 데이터 활용에 동의하는 방식은 `Login for Game Data Usage`와 OpenID/OAuth 흐름을 별도로 구현해야 합니다.

공식 안내상 게임 데이터 활용 로그인은 사용자가 넥슨 계정으로 로그인해 서비스에 게임 데이터 활용 동의를 제공하는 구조입니다. 배포 서비스에서는 Friends 프로그램 또는 서비스 단계 권한 검토가 필요할 수 있으므로, 현재는 `src/auth.py`에 TODO 안내 구조만 둡니다.

## 공식 API 엔드포인트

공식 메이플스토리 확률 정보 조회 API 기준입니다.

- 스타포스 강화 결과 조회: `GET https://open.api.nexon.com/maplestory/v1/history/starforce`
- 잠재능력 재설정 이용 결과 조회: `GET https://open.api.nexon.com/maplestory/v1/history/potential`
- 큐브 사용 결과 조회: `GET https://open.api.nexon.com/maplestory/v1/history/cube`

세 API 모두 `count`와 `date` 또는 `cursor`를 사용합니다. 스타포스도 `ouid`, `start_date`, `end_date`를 직접 받지 않습니다.

스타포스 실제 호출 방식:

- 첫 페이지: `/maplestory/v1/history/starforce?date=YYYY-MM-DD&count=1000`
- 다음 페이지: `/maplestory/v1/history/starforce?cursor=next_cursor&count=1000`

스타포스는 날짜 범위를 직접 받지 않으므로, 앱 내부에서 사용자가 선택한 시작일~종료일을 하루 단위로 순회하며 호출합니다.

응답 리스트 key:

- 스타포스: `starforce_history`
- 잠재능력 재설정: `potential_history`
- 큐브: `cube_history`

## 데이터 수집 범위

- 스타포스 데이터 조회 가능 시작일: 2023-12-27
- 잠재능력 재설정 데이터 조회 가능 시작일: 2024-01-25
- 큐브/스타포스/잠재능력 데이터는 최대 2년 범위 제공
- 스타포스 확률 정보 반영 지연: 최대 5분
- 큐브/잠재능력 재설정 확률 정보 반영 지연: 최대 30분

앱은 오늘 날짜 기준으로 최근 2년 범위만 선택할 수 있게 제한하고, 잘못된 기간이 입력되면 자동 보정합니다.

예를 들어 오늘이 `2026-05-04`라면 조회 가능 기간은 `2024-05-05 ~ 2026-05-04`입니다.

## 스타포스가 안 불러와질 때 체크리스트

1. API Key가 유효하고 권한이 있는지 확인합니다.
2. 조회 기간이 2023-12-27 이후이면서 최근 2년 범위인지 확인합니다.
3. 해당 기간에 실제 스타포스 강화 기록이 있는지 확인합니다.
4. 방금 강화한 기록은 최대 5분 뒤 확인될 수 있습니다.
5. API 디버그 탭에서 path, `params`, response keys, `count`, `record_key_exists`, `record_count`, `next_cursor_exists`를 확인합니다.
6. `params` 안에 첫 요청은 `date`와 `count`, 다음 요청은 `cursor`와 `count`만 들어가는지 확인합니다.
7. 기간을 최근 7일 또는 최근 30일로 줄여 테스트 호출 버튼을 눌러봅니다.

## 운 점수 산식

MVP에서는 전체 유저 평균 API가 제공되지 않으므로 개인 히스토리 내부 평균을 기준으로 그룹별 상대 점수를 계산합니다.

```text
그룹 운 점수 = 50 + (그룹 성공률 - 개인 전체 성공률) * 100
```

전체 리포트 카드의 운 점수는 외부 기준 확률이 없기 때문에 중립값인 50점을 표시합니다. 향후 공식 확률표 또는 전체 유저 집계 데이터가 확보되면 기준 확률 대비 점수로 교체할 수 있습니다.

## 큐브 유효옵션 분석 기준

유효옵션률은 사용자가 선택한 직업명과 주스탯/유효옵션 기준에 따라 계산합니다.

```text
유효옵션 출현률 = 유효옵션이 1줄 이상 포함된 큐브 결과 수 / 전체 큐브 사용 횟수
```

기본 직업 매핑 예시:

- 궁수 계열/메르세데스/보우마스터/신궁/패스파인더/카인/와일드헌터: DEX, 공격력, 올스탯, 보스 데미지, 방어율 무시, 크리티컬 데미지
- 전사 계열/히어로/팔라딘/다크나이트/아델/아란/소울마스터/데몬슬레이어/카이저/제로: STR, 공격력, 올스탯, 보스 데미지, 방어율 무시, 크리티컬 데미지
- 마법사 계열/아크메이지/비숍/에반/루미너스/일리움/라라/키네시스/배틀메이지: INT, 마력, 올스탯, 보스 데미지, 방어율 무시, 크리티컬 데미지
- 도적 계열/나이트로드/섀도어/듀얼블레이드/팬텀/카데나/호영/칼리: LUK, 공격력, 올스탯, 보스 데미지, 방어율 무시, 크리티컬 데미지
- 해적 힘 계열/바이퍼/캐논슈터/스트라이커/아크: STR, 공격력, 올스탯, 보스 데미지, 방어율 무시, 크리티컬 데미지
- 해적 덱스 계열/캡틴/메카닉/엔젤릭버스터: DEX, 공격력, 올스탯, 보스 데미지, 방어율 무시, 크리티컬 데미지
- 제논: STR, DEX, LUK, 공격력, 올스탯, 보스 데미지, 방어율 무시, 크리티컬 데미지
- 데몬어벤져: 최대 HP, 공격력, 보스 데미지, 방어율 무시, 크리티컬 데미지

사냥용, 보스용, 드랍용 기준은 서로 다를 수 있으므로 사용자가 직접 기준을 수정할 수 있게 만들었습니다.

## 1시간 단위 시간 분석

기존 4구간 시간대 분석을 유지하면서 `0시`부터 `23시`까지 1시간 단위 성공률/유효옵션률을 추가했습니다. 시도 횟수가 3회 미만인 시간은 “표본 적음”으로 표시됩니다.

## 채널 분석 가능 여부

채널 정보는 API 응답 또는 CSV에 `channel`, `channel_name`, `channel_no`, `ch`, `server_channel` 같은 필드가 있을 때만 분석합니다. 공식 응답에 채널 필드가 없거나 결측이 많으면 아래 문구를 표시합니다.

```text
현재 API 응답에서 채널 정보가 제공되지 않아 채널별 분석은 제외되었습니다.
```

## 데이터 품질/주의 문구

- 본 서비스는 Nexon Open API로 조회 가능한 본인 히스토리를 기반으로 한 개인 통계 리포트입니다.
- 운 점수와 유효옵션률은 과거 데이터의 상대적 통계이며, 미래 성공을 보장하지 않습니다.
- API 응답에 채널 정보가 없을 경우 채널별 분석은 제공하지 않습니다.
- Nexon Open API로 수집한 데이터는 정책상 30일 이내 갱신 의무가 있을 수 있으므로, 배포 시 최신 정책을 확인해야 합니다.
- API Key는 저장하지 않으며, 사용자의 세션에서만 사용합니다.

## 한계점

- 전체 유저 평균이나 기대값 기준 확률표를 아직 반영하지 않습니다.
- 넥슨 게임 데이터 활용 로그인은 TODO 안내 상태이며 실제 OAuth/OpenID 연동은 미구현입니다.
- 유효옵션 기준은 사용자가 선택한 통계 기준이며 절대적인 정답이 아닙니다.
- API 응답에 제공되지 않는 채널, 비용, 직업 정보는 임의로 만들지 않습니다.

- 사냥용/보스용/드랍용 유효옵션 프리셋

- 리포트 이미지 저장 기능
- 공유용 요약 카드 이미지 생성
